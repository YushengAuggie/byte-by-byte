## 💡 核心概念 / Core Concepts

### 1. 类型化 Props / Typed Props

```typescript
// ❌ Bad — no typing, anything goes
const Button = ({ label, onClick, disabled }) => { ... }

// ✅ Good — explicit interface
interface ButtonProps {
  label: string;
  onClick: () => void;         // no arguments, no return
  disabled?: boolean;          // optional with ?
  variant?: "primary" | "danger" | "ghost";  // union type
}

const Button: React.FC<ButtonProps> = ({
  label,
  onClick,
  disabled = false,
  variant = "primary"
}) => (
  <button
    onClick={onClick}
    disabled={disabled}
    className={`btn btn-${variant}`}
  >
    {label}
  </button>
);
```

### 2. 事件类型 / Event Types

```typescript
// The most common event types you'll use daily
const handleInputChange = (e: React.ChangeEvent<HTMLInputElement>) => {
  console.log(e.target.value);    // string
};

const handleFormSubmit = (e: React.FormEvent<HTMLFormElement>) => {
  e.preventDefault();
  // ...
};

const handleButtonClick = (e: React.MouseEvent<HTMLButtonElement>) => {
  console.log(e.currentTarget);  // typed as HTMLButtonElement
};

// Complete form component
interface SearchFormProps {
  onSearch: (query: string) => void;
}

const SearchForm: React.FC<SearchFormProps> = ({ onSearch }) => {
  const [query, setQuery] = React.useState("");

  return (
    <form onSubmit={(e: React.FormEvent<HTMLFormElement>) => {
      e.preventDefault();
      onSearch(query);
    }}>
      <input
        value={query}
        onChange={(e: React.ChangeEvent<HTMLInputElement>) =>
          setQuery(e.target.value)
        }
        aria-label="search"
      />
      <button type="submit">Search</button>
    </form>
  );
};
```

### 3. 类型化 Refs / Typed Refs

```typescript
// useRef needs a type parameter
const inputRef = React.useRef<HTMLInputElement>(null);
//                                   ↑ DOM element type
//                                              ↑ initial value

// Usage: always check for null (could be before mount)
const focusInput = () => {
  if (inputRef.current) {
    inputRef.current.focus();   // TypeScript knows this is HTMLInputElement!
    inputRef.current.select();  // .select() also valid
  }
};

// Full example: Auto-focus on mount
const AutoFocusInput: React.FC = () => {
  const inputRef = React.useRef<HTMLInputElement>(null);

  React.useEffect(() => {
    inputRef.current?.focus();  // optional chaining: safe if null
  }, []);

  return <input ref={inputRef} aria-label="auto-focus-input" />;
};
```

## 🧠 猜猜输出 / What's the Output?

```typescript
interface CardProps {
  title: string;
  count?: number;
}

const Card: React.FC<CardProps> = ({ title, count = 0 }) => {
  return <div>{title}: {count + 1}</div>;
};

// Usage:
<Card title="Users" />
<Card title="Posts" count={5} />
```

**输出 / Output is:**
- A: `Users: 0` | `Posts: 5`
- B: `Users: 1` | `Posts: 6`
- C: `Users: NaN` | `Posts: 6`
- D: TypeScript error — count is required

**答案 / Answer: B** — `count` defaults to `0`, so `0 + 1 = 1`. Second renders `5 + 1 = 6`.

## ❌ vs ✅ Common Mistakes

**坑 1: onClick 类型写错**
```typescript
// ❌ Wrong — MouseEvent is from the DOM API, not React
onClick: (e: MouseEvent) => void;

// ✅ Correct — React's synthetic event
onClick: (e: React.MouseEvent<HTMLButtonElement>) => void;
```

**坑 2: useRef 初始值**
```typescript
// ❌ Wrong — initial value undefined causes issues
const ref = useRef<HTMLInputElement>();

// ✅ Correct — use null for DOM refs
const ref = useRef<HTMLInputElement>(null);

// ✅ Also correct — for mutable values (not DOM)
const countRef = useRef<number>(0);
```

**坑 3: children 类型**
```typescript
// ❌ Old pattern — React.FC injects children automatically (deprecated in React 18)
const Wrapper: React.FC = ({ children }) => <div>{children}</div>;  // TS error!

// ✅ Correct — explicitly type children
interface WrapperProps {
  children: React.ReactNode;
}
const Wrapper: React.FC<WrapperProps> = ({ children }) => <div>{children}</div>;
```

## 🧭 何时用 / When to Use

| 场景 | 方案 |
|------|------|
| 组件需要接收数据 | 定义 `interface XxxProps` |
| 处理用户输入 | `React.ChangeEvent<HTMLInputElement>` |
| 访问 DOM 节点 | `useRef<HTMLElement>(null)` |
| 传递子组件 | `children: React.ReactNode` |
| 组件包装器 | `React.ComponentProps<"button">` — inherit all native props |

## 🧒 ELI5

TypeScript 就像给积木零件贴标签——方块只能插方孔，圆球只能插圆孔。如果你试着把圆球塞进方孔，还没搭好你就知道出错了，不用等整个积木城堡倒塌。

TypeScript is like labeling LEGO pieces — square pegs only fit square holes, round pegs only fit round holes. If you try to force the wrong shape, you find out immediately — not after your entire LEGO castle collapses.
