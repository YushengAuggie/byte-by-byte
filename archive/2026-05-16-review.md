## Mini Quiz: Days 41-44

**Q1: [System Design] What are the two main components of a distributed task queue like Celery, and what role does each play?**
A1: A **message broker** (e.g., Redis or RabbitMQ) holds the task queue and delivers tasks to workers; **worker processes** pull tasks, execute them, and report results. The broker decouples task producers from consumers, enabling horizontal scaling of workers independently.

**Q2: [Algorithms] In Floyd's Cycle Detection (used in Linked List Cycle), why does the fast pointer always catch the slow pointer inside the cycle?**
A2: Once both pointers are inside the cycle, the fast pointer gains 1 step per iteration on the slow pointer. The gap closes by 1 each step, so it's guaranteed to reach 0 (meet) within `cycle_length` iterations — never "jumping over" the slow pointer.

**Q3: [AI/ML] What is quantization in LLMs, and what is the practical tradeoff between INT8 and FP16 quantization?**
A3: Quantization reduces weight precision (e.g., FP32 → INT8) to shrink model size and speed up inference. INT8 uses 4× less memory than FP32 with ~1-2% accuracy loss; FP16 uses 2× less with negligible loss. INT4 (via GPTQ/AWQ) allows running 70B models on consumer GPUs but with more noticeable quality degradation on complex tasks.
