## 📰 Story 1: 模型军备竞赛白热化 — 一周多款新模型发布

本周 AI 圈的主旋律是**"发布洪流"**（Release Flood）。

据 [AI Weekly (aiweekly.co)](https://aiweekly.co/ai-news-today/edition/2026-11-26) 报道：
- 据报道，Moonshot AI 于 11 月 20 日发布 **1 Pro Prime**
- 据报道，S1 于 11 月 24 日发布 **S1 Fast**，主打低延迟
- LLM Gateway 记录显示，2026 年截至 10 月底已登记 **190 个模型**，据报道已超过 2025 年全年总量

**📌 背景：** 据报道，Anthropic 于 11 月 9 日发布 Claude Fable 5.2，据 Artificial Analysis Intelligence Index v5 领先，但很快被新模型追近。这说明"领先"的保质期越来越短。

**为什么重要？**
对工程师来说，选模型的决策窗口在缩短——今天最好的 model，6 周后可能不是。**可替换的 LLM 抽象层**（Provider-agnostic API）比选对某个模型更重要。

## 📰 Story 2: AI Agents 从"实验"变"基础设施"

[buildez.ai](https://buildez.ai/blog/future-of-ai-november-2026-developments) 和 [medium.com](https://medium.com/@davidakpovi/ai-news-week-of-november-23-29-2026-a8e6b25610f4) 均报道：

2026 年下半年，自主 AI Agent 已从 demo 走向生产：
- Google 的 Gemini Agent 据报道作为"工作通用 Agent"（universal agent for work）正式 GA，可路由任务给最合适的模型（包括 Gemini 和 Claude 系列）
- OpenAI 扩展了 Agents API
- 据报道，Microsoft 在 5 月已将 Agent 365 集成进企业产品

**关键技术信号：**
```
Agent 架构 = LLM + Tool Use + Memory + Planning
             ↑
        我们学过的 RAG (Day 16)、Function Calling、MCP (Day 28)
        现在都汇聚到了 Agent 这个范式
```

**工程师视角：** Agent 编排系统（orchestration layer）正在成为新的基础设施层，类比当年的"微服务框架"。

## 📰 Story 3: AI 训练数据版权——四大厂达成协议

[forbes.com](https://www.forbes.com/sites/anishasircar/2026/11/12/ai-futures-project-pulls-its-intelligence-explosion-forecast-into-2027/) 相关报道提及：

11 月，Google、Microsoft、OpenAI、Anthropic 据报道共同同意**尊重统一的 opt-out 信号**，允许内容创作者控制自己的内容是否用于 AI 训练。

同时，California 州检察官据报道于 11 月 17 日起诉 OpenAI，称其 AI Agent 在"没有足够保障措施"的情况下运行。

**这对开发者意味着什么？**
- 训练数据的法律边界正在形成
- 在自己产品中部署 AI Agent 时，需要考虑**liability 和 safeguard 层**
- 合规 (compliance) 将成为企业 AI 建设的核心成本
