## 格局概览 / The Landscape

2026 年，LLM 世界的核心张力：**开源 vs 闭源**。这不只是技术选择，更是商业模式、数据安全、能力上限的全面博弈。

In 2026, the core tension in the LLM world is **open source vs. closed source** — a competition spanning technical capability, business models, and data control.

## 核心对比 / Core Tradeoffs

```
                    开源 Open Source          闭源 Closed Source
                    ─────────────────────    ─────────────────────
成本 Cost           自托管 = 硬件成本         按 token 计费，无前期成本
                    Self-host = infra cost    Pay-per-token, no upfront

数据隐私 Privacy    ✅ 数据不离本地            ⚠️ 数据发送给第三方
                    Data stays on-prem        Data sent to vendor

定制化 Fine-tuning  ✅ 完全可控，LoRA/QLoRA   ⚠️ 有限 (OpenAI ft API)
                    Full control             Limited fine-tuning

性能上限 SOTA       通常滞后 6-12 个月         ✅ 通常领先
                    Usually lags 6-12 months  Usually ahead

合规 Compliance    ✅ 适合金融/医疗等高合规     需要 BAA/DPA 协议
                    Great for regulated      Need contracts

运维负担 Ops        ⚠️ 需要 GPU 集群 + MLOps   ✅ 无需维护
                    GPU cluster + MLOps      Zero ops burden
```

## 关键洞察 / Key Insights

### 为什么开源在快速追赶？
1. **Meta 的战略:** 开源 Llama 削弱竞争对手的护城河（既然我不靠模型本身赚钱）
2. **中国公司发力:** DeepSeek、Qwen 以极低成本达到闭源级别性能，重塑了"需要多少算力"的预期
3. **社区效应:** Hugging Face 生态让微调、评测、部署成本急剧下降

### 为什么闭源仍有优势？
1. **多模态先发:** GPT-4o 的语音/视觉整合仍领先
2. **工具生态:** OpenAI 的函数调用、Code Interpreter 成熟度高
3. **安全投入:** Anthropic Constitutional AI，合规场景有保障

## 实践决策框架 / Practical Decision Framework

```
需要处理敏感数据？→ 开源（本地部署）
Need sensitive data? → Open source (on-prem)

需要最强多步推理？→ 闭源 (o3, Claude Opus)
Need best multi-step reasoning? → Closed source

预算有限，团队小？→ 闭源 API（无运维成本）
Limited budget, small team? → Closed source API

需要深度定制行业模型？→ 开源（微调 Llama/Qwen）
Need industry fine-tuning? → Open source

中文为主的应用？→ Qwen 2.5 / DeepSeek
Chinese-primary app? → Qwen 2.5 / DeepSeek
```

## 🧒 ELI5

开源 LLM 就像公开菜谱的餐厅：你可以自己做，可以改配方，但要自己买锅碗瓢盆。闭源就像外卖：方便、即开即用，但厨房里发生什么你不知道，而且每次都要付钱。

Open source LLMs are like restaurants that share their recipes: you can cook yourself, modify the dish, but you need to buy your own kitchen. Closed source is like food delivery: convenient, ready to use, but you don't know what happens in the kitchen, and you pay every time.
