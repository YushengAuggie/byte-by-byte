## MCP (Model Context Protocol) — The USB for AI

> **类别 / Category:** Agents | **阶段 / Phase:** Growth | **预计阅读 / Read time:** 2 min

---

### 🧠 直觉解释 / Intuitive Explanation

想象你的电脑没有USB标准。每个设备都需要专用接口——鼠标一种、键盘一种、硬盘一种。你每次想接新设备都要改电脑硬件。这很蠢对吧？

**MCP (Model Context Protocol) 就是AI工具的USB标准。**

它由Anthropic于2024年底发布，解决了一个核心问题：AI模型（LLMs）如何以统一的方式连接到外部工具、数据库、API？以前每家公司都要自己写集成代码，现在有了MCP，任何AI应用都能"即插即用"地接入MCP服务器。

Imagine your computer had no USB standard. Every device needs a custom port. Annoying, right?

**MCP is the USB standard for AI tools.**

Released by Anthropic in late 2024, it solves a core problem: how can AI models connect to external tools, databases, and APIs in a **unified way**? Before MCP, every company wrote custom integration code. Now any AI app can "plug in" to any MCP server.

### ⚙️ How It Works / 工作原理

```
┌─────────────────────────────────────────────────────┐
│                  MCP Architecture                    │
│                                                     │
│  ┌──────────────┐     MCP Protocol     ┌──────────┐ │
│  │  AI Host     │◄──────────────────►│ MCP      │ │
│  │  (Claude,    │   JSON-RPC over     │ Server   │ │
│  │   Cursor,    │   stdio / HTTP/SSE  │          │ │
│  │   Copilot)   │                     │ Exposes: │ │
│  └──────────────┘                     │ • Tools  │ │
│                                       │ • Resources│
│  MCP Client                          │ • Prompts │ │
│  (built into host)                   └──────────┘ │
│                                                     │
│  Examples of MCP Servers:                          │
│  • Filesystem (read/write local files)             │
│  • GitHub (search repos, create PRs)               │
│  • PostgreSQL (query databases)                    │
│  • Slack (send messages, search)                   │
│  • Brave Search (web search)                       │
└─────────────────────────────────────────────────────┘
```

**三个核心原语 / Three Core Primitives:**
1. **Tools** (工具) — Functions the AI can call (e.g., `search_web`, `create_file`)
2. **Resources** (资源) — Data the AI can read (e.g., file contents, database rows)
3. **Prompts** (提示词) — Reusable prompt templates exposed by the server

### 🐍 Runnable Python Example

```python
# pip install mcp anthropic

from mcp.server import Server
from mcp.server.stdio import stdio_server
import mcp.types as types

# Build a minimal MCP server that exposes a weather tool
app = Server("weather-server")

@app.list_tools()
async def list_tools() -> list[types.Tool]:
    return [
        types.Tool(
            name="get_weather",
            description="Get current weather for a city",
            inputSchema={
                "type": "object",
                "properties": {
                    "city": {"type": "string", "description": "City name"}
                },
                "required": ["city"]
            }
        )
    ]

@app.call_tool()
async def call_tool(name: str, arguments: dict) -> list[types.TextContent]:
    if name == "get_weather":
        city = arguments["city"]
        # In real code: call a weather API here
        return [types.TextContent(
            type="text",
            text=f"Weather in {city}: 72°F, sunny ☀️"
        )]

# Run the server (Claude Desktop can now connect to it!)
if __name__ == "__main__":
    import asyncio
    asyncio.run(stdio_server(app))
```

Connect this to Claude Desktop via `claude_desktop_config.json` and Claude can now call `get_weather` as a native tool!

### 🌐 Applications / 应用场景

| Use Case | MCP Server |
|----------|-----------|
| AI reads/writes your codebase | Filesystem MCP |
| AI creates GitHub PRs | GitHub MCP |
| AI queries your database | PostgreSQL MCP |
| AI searches the web | Brave Search MCP |
| AI books calendar events | Google Calendar MCP |
| AI reads company docs | Notion/Confluence MCP |

**为什么重要 / Why It Matters:**
- 标准化 → 生态繁荣（类比：npm为JS，MCP为AI工具）
- 安全 → MCP服务器可控制权限，AI不能随意访问
- 可组合 → 一个AI客户端可同时接多个MCP服务器

---

### ⚡ MCP vs Function Calling

| | Function Calling | MCP |
|--|--|--|
| 标准化 | 各厂商自定义 | 统一协议 |
| 服务器端部署 | 不支持 | 支持 |
| 资源访问 | 无 | 支持 (Resources) |
| 跨模型兼容 | ❌ | ✅ |

### 🧒 ELI5

以前AI想用工具，就像每次换手机都要重新教它所有的按钮。MCP就是给AI装了个"学徒手册"：任何工具只要按格式写好，AI就能立刻会用，不用每次重新配置。就像学会了用筷子，就能夹任何菜。

Before MCP, teaching an AI a new tool was like rewriting the instruction manual every time. MCP is a standard instruction format — any tool written to spec can be used by any AI immediately. Like learning chopsticks: once you know the technique, you can pick up any food.
