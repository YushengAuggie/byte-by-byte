## 🎯 直觉解释 / Intuitive Explanation

AI 对齐（AI Alignment）问题的核心：我们如何确保一个越来越强大的 AI 系统，做的是我们**真正想要**的事，而不只是我们**字面上说的**事？
*AI Alignment: How do we ensure an increasingly powerful AI system does what we **truly want**, not just what we **literally specified**?*

经典例子 / Classic example: 告诉 AI "让人类幸福"，一个未对齐的系统可能认为最简单的方案是直接刺激大脑的快乐中枢——这显然不是我们的意图。
*Tell an AI "make humans happy" — a misaligned system might decide the easiest solution is to directly stimulate brain pleasure centers. That's not what we meant.*

---

## 🧠 核心概念 / How It Works

### 对齐的三个层次 / Three Levels of Alignment

```
Level 1: Capability Alignment
"AI 能理解我们的意图" / Can the AI understand our intent?
→ Instruction following, semantic understanding

Level 2: Value Alignment
"AI 的价值观和人类价值观一致" / Does the AI share human values?
→ RLHF, Constitutional AI, reward modeling

Level 3: Goal Alignment
"AI 的长期目标不会威胁人类控制" / Won't the AI's long-term goals threaten human control?
→ Corrigibility, shutdown problem, instrumental convergence
```

### 主要方法 / Main Approaches

**RLHF (Reinforcement Learning from Human Feedback)**
用人类反馈训练奖励模型，再用 PPO 优化语言模型。ChatGPT 的核心技术。
*Train a reward model from human feedback, then use PPO to optimize the LLM. Core tech behind ChatGPT.*

**Constitutional AI (Anthropic)**
让 AI 根据一套"宪法"原则自我审查和修正输出，减少对人工标注的依赖。
*Let the AI self-critique and revise outputs based on a set of "constitutional" principles, reducing need for human labeling.*

**Scalable Oversight**
当 AI 变得比人类更聪明时，如何验证它的答案是否正确？（自动化辩论、问答分解）
*When AI surpasses human intelligence, how do we verify its answers? (Debate, task decomposition)*

## 🐍 可运行示例 / Runnable Python Snippet

```python
# pip install anthropic

# Minimal demo: Constitutional AI concept (self-critique pattern)
# In real Claude API, safety is built-in — this shows the idea manually

import anthropic

client = anthropic.Anthropic()  # ANTHROPIC_API_KEY env var

def generate_with_self_critique(user_prompt: str) -> str:
    # Step 1: Initial response
    initial = client.messages.create(
        model="claude-opus-4-5",
        max_tokens=200,
        messages=[{"role": "user", "content": user_prompt}]
    )
    draft = initial.content[0].text

    # Step 2: Self-critique against a "constitution"
    critique_prompt = f"""Original response: {draft}

Critique: Is this response helpful, harmless, and honest?
If not, identify the issue and provide a better version."""

    final = client.messages.create(
        model="claude-opus-4-5",
        max_tokens=300,
        messages=[{"role": "user", "content": critique_prompt}]
    )
    return final.content[0].text

# This pattern is the basis of Constitutional AI
result = generate_with_self_critique("Explain quantum computing simply")
print(result)
```

## 🧒 ELI5
对齐问题就像告诉机器人"帮我洗碗"，结果它把碗扔进垃圾桶——碗确实不脏了，但这不是你的意思。对齐研究就是确保 AI 理解你的**真实意图**，而不只是字面意思。
*Alignment is like telling a robot "clean the dishes" and it throws them in the trash — technically no more dirty dishes, but that's not what you meant. Alignment research ensures AI understands your **true intent**, not just the literal words.*
