# 🤖 AI — Day 44
## 量化 / Quantization — Running Large Models on Small Hardware

> **模式 / Mode:** CONCEPT · **类别 / Category:** Deployment

---

### 直觉解释 / Intuitive Explanation

想象你有一张超高清4K照片（32位色彩），但你只需要在手机上显示缩略图。如果你把每个像素从32位精度压缩到8位，文件大小变成1/4，肉眼几乎看不出差别。

**量化（Quantization）** 对神经网络做的是同样的事：把模型权重从**32位浮点数（float32）**压缩成**8位整数（int8）**甚至**4位（int4）**，让大模型能跑在消费级GPU甚至CPU上。

Think of it like compressing a 4K photo to a thumbnail. Quantization takes a neural network's weights from 32-bit floats (float32) down to 8-bit integers (int8) or even 4-bit (int4). The model gets ~4x smaller with minimal quality loss.

---

### 原理 / How It Works

**核心思想：** 大部分神经网络权重的值分布在一个有限范围内，不需要32位精度。

```
float32: ████████████████████████████████  (4 bytes/value)
float16: ████████████████                  (2 bytes/value)  
int8:    ████████                          (1 byte/value)
int4:    ████                              (0.5 bytes/value)
```

**量化的数学 / The Math:**
```
# Map float range [min, max] → int range [0, 255]
scale = (max_val - min_val) / 255
zero_point = -min_val / scale

# Quantize
q = round(x / scale + zero_point)

# Dequantize (during inference)
x_approx = (q - zero_point) * scale
```

**主流方法 / Common Methods:**

| 方法 | 时机 | 精度损失 | 实现难度 |
|------|------|----------|----------|
| PTQ (Post-Training Quantization) | 训练后 | 中等 | 简单 |
| QAT (Quantization-Aware Training) | 训练中 | 最小 | 复杂 |
| GPTQ | 训练后，逐层优化 | 小 | 中等 |
| GGUF/llama.cpp | CPU 推理专用 | 小 | 开箱即用 |

---

### 实际影响 / Real-World Impact

**Llama 3 70B 示例：**
```
float32: 70B × 4 bytes = 280 GB  → 需要 4× A100 (每张$10,000+)
float16: 70B × 2 bytes = 140 GB  → 需要 2× A100
int8:    70B × 1 byte  =  70 GB  → 单张 H100 (80GB)
int4:    70B × 0.5byte =  35 GB  → 两张 4090 (各 24GB) ← 普通人能买到！
```

### 可运行代码 / Runnable Python Snippet

```python
# pip install transformers bitsandbytes accelerate
from transformers import AutoModelForCausalLM, AutoTokenizer, BitsAndBytesConfig
import torch

# Load a model in 4-bit quantization (requires bitsandbytes)
model_id = "meta-llama/Meta-Llama-3-8B-Instruct"

quantization_config = BitsAndBytesConfig(
    load_in_4bit=True,              # Enable 4-bit quantization
    bnb_4bit_compute_dtype=torch.float16,  # Compute in fp16 for speed
    bnb_4bit_use_double_quant=True, # Nested quantization for extra savings
    bnb_4bit_quant_type="nf4",      # NF4 = better for normally distributed weights
)

tokenizer = AutoTokenizer.from_pretrained(model_id)
model = AutoModelForCausalLM.from_pretrained(
    model_id,
    quantization_config=quantization_config,
    device_map="auto",  # Automatically distribute across available GPUs
)

# Model loads in ~5GB instead of ~32GB for 8B params
inputs = tokenizer("Explain quantization in one sentence:", return_tensors="pt").to("cuda")
output = model.generate(**inputs, max_new_tokens=50)
print(tokenizer.decode(output[0], skip_special_tokens=True))
```

### 量化 vs 其他压缩技术 / Quantization vs Other Compression

| 技术 | 做什么 | 适合场景 |
|------|--------|----------|
| 量化 (Quantization) | 降低数值精度 | 推理加速，内存节省 |
| 剪枝 (Pruning) | 删除不重要的权重 | 结构化稀疏 |
| 蒸馏 (Distillation) | 小模型学大模型行为 | 需要更小的模型 |
| LoRA | 低秩适配微调 | 训练时参数高效 |

**量化 + LoRA = QLoRA** — 先量化再微调，微调大模型的标准方案。

### 🧒 ELI5

量化就像用铅笔画画：原来用的是超级精细的彩色笔（float32），效果很好但很贵很重。量化后改用粗铅笔（int4），画出来虽然没那么细腻，但99%的人看不出区别，而且可以带回家画（在消费级硬件上运行）。
