### 1. OpenAI GPT-5.6 家族发布 — 三款专用变体
OpenAI 推出 GPT-5.6 家族，三款各有分工：
- **Sol** — 重推理任务（类似 o3）

## 🔥 工程师视角：这周学什么？

**Agent 安全**变成了必修课。构建 agent 系统的工程师，记住这三条：
1. **最小权限**：agent 只能访问它需要的资源
2. **输入验证**：防止 prompt injection / tool abuse
3. **可观测性**：每个 agent 动作都要有日志和审计

```python
# 不好的做法：agent 可以执行任意 shell
def agent_tool(command: str):
    import subprocess
    return subprocess.run(command, shell=True)  # ❌ Dangerous

# 好的做法：白名单 + 沙箱
ALLOWED_TOOLS = {"search", "read_file", "write_file"}
def agent_tool(tool_name: str, params: dict):
    if tool_name not in ALLOWED_TOOLS:
        raise PermissionError(f"Tool {tool_name} not allowed")
    return TOOL_REGISTRY[tool_name](**params)  # ✅ Bounded
```
