**Q1: [💻 Algorithms — Edit Distance (Day 151)]**

给定两个字符串 `word1 = "horse"`, `word2 = "ros"`，Edit Distance 的 DP 递推公式是什么？当 `word1[i-1] == word2[j-1]` 和不等时分别如何处理？

Given `word1 = "horse"` and `word2 = "ros"`, what is the DP recurrence for Edit Distance? How does it differ when characters match vs. don't match?

<details><summary>显示答案 / Show Answer</summary>

**核心递推 / Core Recurrence:**

```python
if word1[i-1] == word2[j-1]:
    dp[i][j] = dp[i-1][j-1]          # characters match — free move
else:
    dp[i][j] = 1 + min(
        dp[i-1][j],    # delete from word1
        dp[i][j-1],    # insert into word1
        dp[i-1][j-1]   # replace
    )
```

**关键洞察 / Key Insight:** `dp[i][j]` 表示将 `word1[:i]` 转换成 `word2[:j]` 的最少操作数。字符相等时不用操作，直接继承对角线。字符不等时取"删、插、换"三种操作的最小值加1。

Base cases: `dp[i][0] = i` (delete all), `dp[0][j] = j` (insert all). Time: O(m×n), Space: O(m×n), optimizable to O(n).

</details>

**Q2: [💻 Algorithms — Longest Increasing Path in a Matrix (Day 152)]**

为什么 Longest Increasing Path in a Matrix 不能用标准 BFS/DFS，而必须用 **DFS + 记忆化**？如果用普通 DFS 会出现什么问题？

Why can't Longest Increasing Path in a Matrix use a standard BFS/DFS without memoization? What goes wrong with plain DFS?

<details><summary>显示答案 / Show Answer</summary>

**问题所在 / The Problem:** 普通 DFS 会对同一个格子重复计算。比如多条路径都经过格子 (2,3)，每次到达都要重新搜一遍它能延伸的最长路径——这会导致指数级时间复杂度。

**为什么不需要 `visited` 数组 / Why no visited set?** 因为路径是**严格递增**的，不可能形成环。从任意格子出发，只能往更大的数走，天然防止重访。

**正确做法 / Correct Approach:**

```python
from functools import lru_cache

def longestIncreasingPath(matrix):
    rows, cols = len(matrix), len(matrix[0])
    
    @lru_cache(maxsize=None)
    def dfs(r, c):
        best = 1
        for dr, dc in [(0,1),(0,-1),(1,0),(-1,0)]:
            nr, nc = r + dr, c + dc
            if 0 <= nr < rows and 0 <= nc < cols and matrix[nr][nc] > matrix[r][c]:
                best = max(best, 1 + dfs(nr, nc))
        return best
    
    return max(dfs(r, c) for r in range(rows) for c in range(cols))
```

记忆化将时间从 O(2^(m×n)) 降至 O(m×n)。每个格子只计算一次。

</details>

**Q3: [💻 Algorithms — Burst Balloons + Distinct Subsequences (Days 153–154)]**

区间 DP（Interval DP）的核心思维是什么？以 Burst Balloons 为例，为什么我们要**反向思考**（想"最后戳哪个气球"而不是"最先戳哪个"）？

What is the core insight of Interval DP? In Burst Balloons, why do we think about **the last balloon to burst** in a range, rather than the first?

<details><summary>显示答案 / Show Answer</summary>

**反向思维的原因 / Why Reverse Thinking:**

如果想"第一个戳哪个"，戳完之后左右两边的气球会**合并**，导致子问题的边界状态不固定，无法拆解成独立的子问题。

If we ask "which balloon to burst first?", after bursting it the left and right halves **merge** — the subproblems become entangled and can't be solved independently.

**反向思维 / Reverse Thinking:** 问"区间 `[l, r]` 中**最后**戳哪个气球 `k`？"最后戳 `k` 时，它的左右邻居就是 `nums[l-1]` 和 `nums[r+1]`（边界），这是**固定的**，子问题 `[l, k-1]` 和 `[k+1, r]` 完全独立。

```python
# dp[l][r] = max coins from bursting all balloons in range [l, r]
for length in range(1, n+2):
    for l in range(1, n+2-length):
        r = l + length - 1
        for k in range(l, r+1):  # k is the LAST to burst
            dp[l][r] = max(dp[l][r],
                nums[l-1]*nums[k]*nums[r+1] + dp[l][k-1] + dp[k+1][r])
```

**通用规律 / General Rule:** 区间 DP 的枚举顺序是**从短到长**（先解决小区间，再合并成大区间）。适用场景：合并石头、矩阵链乘法、戳气球、回文分割等。

</details>
