## 核心问题：AGI 什么时候到来？/ The Core Question: When Does AGI Arrive?

AGI (Artificial General Intelligence，通用人工智能) = 能在任意认知任务上达到人类水平的 AI。现在的 LLM 很强，但到底离 AGI 有多远？这是 AI 领域最大的争论。

AGI = AI that matches or exceeds human performance on any cognitive task. Current LLMs are impressive — but how far are we, really?

## 当前架构的局限 / Current Architecture Limits

Transformer 很强，但有几个根本性限制：

### 1. 二次方复杂度问题 (Quadratic Attention)
```
Context length = N tokens
Attention 计算量 = O(N²)
N = 100K tokens → 10B 次计算
N = 1M tokens  → 1T 次计算 (实际不可行)
```

### 2. 无真正"状态记忆"
Transformer 每次推理都是无状态的。"记忆"只是把历史全塞进 context window，本质上是**昂贵的查找，不是真正的记忆**。

### 3. 推理 ≠ 理解
LLM 在 benchmark 上强，但遇到分布外问题（out-of-distribution）会犯低级错误。这是 "stochastic parrot" 批评的核心。

## 新兴架构 / Emerging Architectures

### 🔷 State Space Models (SSM) — Mamba
```
Transformer: O(N²) attention
Mamba:       O(N) linear recurrence

关键思路：
  用选择性状态更新 (selective state updates) 替代全量 attention
  每个 token 只更新相关的隐藏状态，忽略无关信息
```

优势：长序列性能线性增长，推理内存大幅减少  
现实：在某些任务上与 Transformer 持平，但多模态和代码任务仍落后

### 🔷 混合专家模型 (Mixture of Experts, MoE) — 已投入生产
```python
# 概念示例
class MoE(nn.Module):
    def forward(self, x):
        # Router: 每个 token 只激活 top-K 个专家 (e.g., k=2/8)
        expert_weights = self.router(x)  # sparse selection
        outputs = [expert(x) for expert in self.experts]
        return sum(w * o for w, o in zip(expert_weights, outputs))
```

GPT-4 据报道是 MoE 架构（8 个专家，每次激活 2 个）。总参数量大，但每次推理只用 1/4 的参数 → **参数量大 + 计算量小**。

### 🔷 Test-Time Compute Scaling — 最新趋势
与其在训练时用更多算力（更大模型），不如在**推理时动态增加思考时间**：

```
简单问题: 直接回答 (1x compute)
难题:     CoT + Self-verify + Multiple attempts (10x compute)
超难题:   MCTS 搜索 + Reflection loops (100x compute)
```

这就是 OpenAI o1/o3、DeepSeek-R1 背后的思路：**推理时 scaling，不只是训练时 scaling**。

## 简单 Python 代码演示 / Python Demo

演示 Test-Time Compute 的核心思路：多次尝试 + 自我验证：

```python
import anthropic  # pip install anthropic

def solve_with_test_time_compute(problem: str, n_attempts: int = 3) -> str:
    """
    Simple test-time compute: try N times, verify each, return best
    In practice: o1 uses MCTS + internal reward model, much more complex
    """
    client = anthropic.Anthropic()
    attempts = []

    for i in range(n_attempts):
        # Each attempt uses CoT
        response = client.messages.create(
            model="claude-opus-4-5",
            max_tokens=1024,
            messages=[{
                "role": "user",
                "content": f"Think step by step: {problem}"
            }]
        )
        attempts.append(response.content[0].text)

    # Self-verification: ask model to pick best answer
    verify_prompt = f"These are {n_attempts} solutions. Which is most likely correct?\n"
    for i, a in enumerate(attempts):
        verify_prompt += f"\nSolution {i+1}: {a[:200]}..."

    verdict = client.messages.create(
        model="claude-opus-4-5",
        max_tokens=256,
        messages=[{"role": "user", "content": verify_prompt}]
    )
    return verdict.content[0].text
```

## 🧒 ELI5

AGI 的争论就像争论"什么时候能造出会真正思考的机器"。

现在的 AI（LLM）就像一个读了所有书的人，记性超好，能写作文，但：
- 没有真正理解物理世界（不知道"把球推下去，球会滚"）
- 没有长期记忆（每次对话都是第一次见面）
- 遇到没见过的题目容易乱答

新架构（Mamba、MoE、Test-Time Scaling）就像给这个人加上了：
- 更高效的大脑（Mamba：不用每次把所有记忆翻一遍）
- 专科专家团队（MoE：遇到数学题找数学专家，遇到写作题找写作专家）
- 多想一会儿的能力（Test-Time Compute：难题多思考几步再回答）

AGI 什么时候来？聪明人们争论了几十年，结论只有一个：**定义不同，答案不同。** 🤷
