## 🌏 本周 AI 三大动态 / Top 3 Stories This Week

### 1. 模型价格战：大模型全面降价 / The Great Model Price War
**来源:** https://llm-stats.com/ai-news · https://medium.com/@davidakpovi/ai-news-week-of-july-6-to-july-12-2026-f81a26c49c55

本月初，多家主要 AI 公司几乎同步发布新模型，引发业界称之为"Great Model Price War"（大模型价格战）的局面：

- **Grok 4.5**（xAI/SpaceX，7月8日）
- **GPT-5.6**（OpenAI，7月9日）：三个变体 Sol / Terra / Luna；据报道 Luna 每百万输出 token 约 $6，较之前旗舰大幅降低
- **Kimi K3**（Moonshot AI，7月16日）：据报道是一个约 2.8T 参数的 MoE 稀疏模型，1M token 上下文窗口，承诺于 7月27日开源权重

**为什么重要 / Why it matters:**  
价格竞争加速 AI 普及，对开发者和企业来说意味着 API 成本可能继续下降。但模型能力趋同后，下一个差异化可能是**专业化**（代码、医疗、多模态）而非规模。

---

### 2. 推理效率新突破：ICML 2026 "选择性激活稀疏" / Selective Activation Sparsity
**来源:** https://kersai.com/ai-breakthroughs-july-2026/ · https://skycrumbs.com/blog/ai-research-july-2026

ICML 2026 上有研究提出了 "selective activation sparsity" 训练方法：模型在推理时只激活与当前任务最相关的参数子集，而非全量激活所有神经元。据报道，该方法在部分基准上以更小的有效参数量达到大模型同级性能。

这与 MoE（Mixture of Experts）思想一脉相承，但在激活粒度上更细。对工程师来说的含义：**未来模型在同等推理成本下可能更强，或同等能力下更便宜**。

---

### 3. Google 品牌整合：NotebookLM → Gemini Notebook / Google Consolidates
**来源:** https://llm-stats.com/ai-news

Google 将旗下 NotebookLM 重命名为 **Gemini Notebook**，并集成了：
- 安全的云端代码执行环境
- 与 Gemini 应用和 Google 搜索的跨平台同步

此外，据泄露信息显示 **Gemini 3.5 Pro** 即将发布，据报道将支持 **2M token 上下文窗口**（如确认将是目前最长上下文之一）。

## 💡 工程师视角 / Engineer's Takeaway

```
趋势总结 / Trend Summary:

1. 价格 ↓ → API 调用成本继续下降，AI 产品 margin 逻辑改变

3. 生态整合 → 大厂在将 AI 工具深度绑定自有生态（Google Workspace, etc）

对你的影响:
• 如果在做 AI 产品：重新评估 API 供应商定价

```
