# 🤖 AI — Reinforcement Learning from AI Feedback (RLAIF)

> Day 58 · Expert Phase · Training Category · ~2 min read

---

## 直觉解释 / Intuitive Explanation

你已经知道 **RLHF** — 让人类标注"哪个回答更好"来训练奖励模型。  
问题：人类标注**慢、贵、难以规模化**。

**RLAIF** 的核心想法：**用一个强 AI（比如 Claude/GPT-4）来替代人类标注者**，让它评判哪个输出更好，再用这些偏好数据训练更小的模型。

You already know **RLHF** — humans label "which response is better" to train a reward model.  
Problem: human annotation is **slow, expensive, hard to scale**.

**RLAIF's core idea:** Use a powerful AI (Claude/GPT-4) as the **AI annotator** instead of humans — it judges which output is better, then those preferences train a smaller model.

---

## 工作原理 / How It Works

```
标准 RLAIF 流程 / Standard RLAIF Pipeline:

Step 1: Supervised Fine-Tuning (SFT)
  Base LLM → fine-tune on instruction-following dataset
  → SFT Model

Step 2: AI Preference Generation
  SFT Model generates: Response A vs Response B
  → Send BOTH to "AI Judge" (e.g., GPT-4, Claude)
  → AI Judge returns: {"preferred": "A", "reason": "..."}
  → Creates preference dataset at scale (no humans!)

Step 3: Reward Model Training
  Train reward model on AI-generated preferences
  → RM: score(response) → float

Step 4: RL Fine-Tuning (PPO)
  Use reward model to fine-tune SFT model
  → Policy maximizes reward (while constrained by KL divergence from SFT)

                         ┌──────────────────┐
                         │   AI Judge       │
                         │ (GPT-4/Claude)   │
                         └────────┬─────────┘
                                  │ preferences
                    ┌─────────────▼──────────────┐
                    │    Reward Model Training    │
                    └─────────────┬──────────────┘
                                  │ reward signal
     SFT Model ──→ PPO Training ──▼──→ Aligned Model
```

---

## RLHF vs RLAIF 对比

| 维度 | RLHF | RLAIF |
|------|------|-------|
| 标注来源 | 人类 | AI 模型 |
| 成本 | 高 (人力) | 低 (API 调用) |
| 速度 | 慢 | 快 (批量) |
| 质量 | 最高 (人类判断) | 高，但有 AI bias |
| 规模化 | 困难 | 容易 |
| 主要风险 | 人类偏差、疲劳 | AI 偏差级联 |

---

## Direct RLAIF (d-RLAIF) — 去掉 Reward Model

Google 提出的变体：**跳过奖励模型训练**，直接用 AI Judge 的评分作为强化学习信号。

```
Standard RLAIF: SFT → AI Preferences → Reward Model → PPO
d-RLAIF:        SFT → AI Preferences → Direct Policy Update (DPO/IPO)
```

优点：更少的训练步骤，更稳定；缺点：依赖 AI Judge 质量更强。

## 应用实例 / Real Applications

- **Constitutional AI (Anthropic Claude):** Claude 的早期训练用 AI 来批判和修改自己的回答，类似 RLAIF
- **Gemini 系列:** Google 报告使用 d-RLAIF 减少了人类标注需求
- **代码模型:** AlphaCode 类系统用 AI 评判代码正确性 + 风格

## 可运行示例 / Runnable Code

```python
# pip install openai
# Simplified RLAIF preference generation example

import openai

def ai_judge_preference(prompt: str, response_a: str, response_b: str) -> dict:
    """Use a strong AI to judge which response is better."""
    
    judge_prompt = f"""You are evaluating two AI responses. 
    
Prompt: {prompt}

Response A: {response_a}

Response B: {response_b}

Which response is better? Reply with JSON: {{"preferred": "A" or "B", "reason": "..."}}"""
    
    client = openai.OpenAI()
    result = client.chat.completions.create(
        model="gpt-4",
        messages=[{"role": "user", "content": judge_prompt}],
        response_format={"type": "json_object"}
    )
    import json
    return json.loads(result.choices[0].message.content)

# Example usage
pref = ai_judge_preference(
    prompt="Explain recursion simply",
    response_a="Recursion is when a function calls itself.",
    response_b="Recursion is like Russian dolls — each doll contains a smaller version of itself."
)
print(pref)
# → {"preferred": "B", "reason": "The analogy makes it more intuitive"}
```

## 关键挑战 / Key Challenges

1. **偏差级联 (Bias Cascade):** AI Judge 的偏见会放大到被训练的模型里
2. **过度优化 (Reward Hacking):** 模型学会"取悦" AI Judge，而不是真正有用
3. **Judge 模型依赖:** 好的 RLAIF 需要一个真的很强的 Judge 模型
4. **Goodhart's Law:** "当度量标准成为目标，它就不再是好的度量标准"

## 🧒 ELI5

老师教学生 (RLHF): 每次学生写作业，老师亲自批改 — 慢但很准确。  
AI 辅助批改 (RLAIF): 先让优等生 (强 AI) 批改大部分作业，老师只审核边界情况 — 快很多，质量几乎一样好。  
风险是优等生也有自己的偏见 🤔。

RLHF = a teacher grading every homework assignment personally. Accurate but slow.  
RLAIF = the top student grades most assignments, teacher only reviews edge cases. Much faster, nearly as good.  
Risk: the top student also has their own biases 🤔.
