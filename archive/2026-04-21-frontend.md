### 🧪 猜猜输出什么？ / What does this output?

```typescript
async function fetchDashboard(userId: string) {
  console.log("A");
  
  const user = await fetch(`/api/users/${userId}`);
  console.log("B");
  
  const [orders, notifications] = await Promise.all([
    fetch(`/api/orders?userId=${userId}`),
    fetch(`/api/notifications?userId=${userId}`)
  ]);
  console.log("C");
  
  return { user, orders, notifications };
}

fetchDashboard("123");
console.log("D");
```

**What logs first?**
- A) A → B → C → D  
- B) A → D → B → C  
- C) D → A → B → C  
- D) A → B → D → C

> **答案 / Answer: B** — `async` functions run synchronously until the first `await`. So "A" logs, then the function suspends at `await fetch(...)`, and "D" logs immediately. When the fetch resolves, "B" logs, then "C" after Promise.all.

### 🔑 Core Concepts

#### Promise 状态机 / Promise State Machine
```
pending → fulfilled (resolve)
        → rejected  (reject)

Once settled, state never changes.
```

#### 三种并发模式 / Three Concurrency Patterns

```typescript
// ❌ Pattern 1: Sequential (串行) — SLOW
const user = await fetchUser(id);      // waits 200ms
const orders = await fetchOrders(id);  // waits another 300ms
// Total: 500ms — unnecessary!

// ✅ Pattern 2: Parallel (并行) — FAST
const [user, orders] = await Promise.all([
  fetchUser(id),    // both start at the same time
  fetchOrders(id),  // 
]);
// Total: max(200ms, 300ms) = 300ms 🚀

// ⚠️ Pattern 3: Promise.allSettled — when you need ALL results
// even if some fail (e.g., non-critical widgets)
const results = await Promise.allSettled([
  fetchUser(id),
  fetchOrders(id),
  fetchNotifications(id),
]);
results.forEach(r => {
  if (r.status === 'fulfilled') console.log(r.value);
  else console.error(r.reason);
});
```

### ❌ Common Mistakes / 常见错误

```typescript
// ❌ Mistake 1: await inside map() — sequential, not parallel
const data = await Promise.all(
  ids.map(id => await fetchUser(id))  // SyntaxError! can't await inside non-async map
);

// ✅ Correct: pass Promise directly
const data = await Promise.all(
  ids.map(id => fetchUser(id))  // no await inside map
);

// ❌ Mistake 2: unhandled rejection
const result = await Promise.all([fetchA(), fetchB()]); // if B rejects, A's result lost!

// ✅ Correct: use allSettled or try/catch per request
const [a, b] = await Promise.allSettled([fetchA(), fetchB()]);

// ❌ Mistake 3: missing error handling
async function loadData() {
  const data = await fetchData(); // throws? crashes silently!
  return data;
}

// ✅ Correct:
async function loadData() {
  try {
    return await fetchData();
  } catch (err) {
    console.error("Failed to load:", err);
    return null; // or throw to parent
  }
}
```

### 🎯 When to Use / When NOT to Use

```
Use Promise.all when:
✅ All requests are independent
✅ You need ALL to succeed (fail fast if any fails)
✅ Performance matters (dashboard loads, batch ops)

Use Promise.allSettled when:
✅ Some failures are acceptable
✅ Non-critical widgets/sections
✅ You need all results regardless of failure

Use sequential await when:
✅ Request B depends on result of A
✅ Ordering matters (database transactions)
✅ You need to avoid rate limiting

Avoid:
❌ await in a for loop when items are independent
❌ new Promise() wrapping async functions (anti-pattern)
❌ .then() chains when async/await is available (less readable)
```

### 🔥 Production Pattern: TypeScript async with error handling

```typescript
type Result<T> = { data: T; error: null } | { data: null; error: Error };

async function safeAsync<T>(promise: Promise<T>): Promise<Result<T>> {
  try {
    const data = await promise;
    return { data, error: null };
  } catch (err) {
    return { data: null, error: err instanceof Error ? err : new Error(String(err)) };
  }
}

// Usage — no try/catch needed at call site:
const { data: user, error } = await safeAsync(fetchUser("123"));
if (error) return <ErrorState message={error.message} />;
```

### 🧒 ELI5

Promise就像点外卖的收据。你点了3个菜（3个请求）。串行 = 等第一个菜上了再点第二个，太慢。`Promise.all` = 同时点3个菜，哪个先好哪个先上，全部好了再吃。`allSettled` = 就算有菜没做出来，你也能知道哪些成功了哪些失败了。

A Promise is like a takeout receipt. You ordered 3 dishes. Sequential = wait for dish 1 before ordering dish 2 (slow!). `Promise.all` = order all 3 at once, eat when all are ready. `allSettled` = even if one fails, you know which succeeded and which didn't.
