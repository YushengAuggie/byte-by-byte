## Quick Quiz: Days 46–49

**Q1: [System Design] What algorithm does Distributed Consensus (Raft/Paxos) use to ensure only one leader at a time?**
A1: Leader election via randomized election timeouts. A node starts an election when it hasn't heard from the leader within its timeout window. Majority quorum (⌊N/2⌋+1) vote required to win.

**Q2: [Algorithms] What technique does "Find the Duplicate Number" use to detect a cycle in O(1) space?**
A2: Floyd's Cycle Detection (tortoise and hare). Treat array values as "next pointers" — a duplicate creates a cycle. The meeting point in Phase 1 leads to the cycle entrance in Phase 2, which is the duplicate.

**Q3: [Python Craft] What's the key difference between asyncio's `gather` and a Semaphore?**
A3: `gather` runs all coroutines concurrently with no limit; a Semaphore caps the concurrency to N at a time. Use Semaphore when calling rate-limited APIs or managing resource pools (e.g., DB connections).
