### 🧠 什么是 AI Agent？/ What Is an AI Agent?

普通 LLM：你问 → 它答 → 结束。一次性的。
*Regular LLM: you ask → it answers → done. One-shot.*

AI Agent：**目标 → 思考 → 行动 → 观察 → 再思考 → 再行动…** 直到完成目标。
*AI Agent: **goal → think → act → observe → think again → act again…** until goal achieved.*

关键区别：Agent 可以**使用工具**（搜索、代码执行、数据库查询）并**自主规划多步骤**任务。
*Key difference: Agents can **use tools** (search, code execution, DB queries) and **autonomously plan multi-step** tasks.*

---

### 🔄 ReAct 框架 / The ReAct Framework

ReAct = **Re**asoning + **Act**ing
来源：2022 年论文 ["ReAct: Synergizing Reasoning and Acting in Language Models"](https://arxiv.org/abs/2210.03629)

**循环 / The Loop:**

```
┌─────────────────────────────────────────┐
│  Goal: "Find the CEO of OpenAI and      │
│         their most recent tweet"        │
└─────────────────────┬───────────────────┘
                      │
        ┌─────────────▼─────────────┐
        │  THOUGHT: I need to search │
        │  for OpenAI's current CEO  │
        └─────────────┬─────────────┘
                      │
        ┌─────────────▼─────────────┐
        │  ACTION: search("OpenAI   │
        │  CEO 2024")               │
        └─────────────┬─────────────┘
                      │
        ┌─────────────▼─────────────┐
        │  OBSERVATION: "Sam Altman  │
        │  is CEO of OpenAI"        │
        └─────────────┬─────────────┘
                      │
        ┌─────────────▼─────────────┐
        │  THOUGHT: Now I need to   │
        │  find his latest tweet    │
        └─────────────┬─────────────┘
                      │
        ┌─────────────▼─────────────┐
        │  ACTION: search("Sam      │
        │  Altman latest tweet")    │
        └─────────────┬─────────────┘
                      │
        ┌─────────────▼─────────────┐
        │  OBSERVATION: [tweet...] │
        └─────────────┬─────────────┘
                      │
        ┌─────────────▼─────────────┐
        │  ANSWER: "Sam Altman is   │
        │  CEO. His latest tweet..." │
        └───────────────────────────┘
```

**为什么有效？** 思考（CoT）让模型推理，行动让它获取外部信息，观察让它根据现实反馈修正计划。
*Why it works: Thinking (CoT) enables reasoning; Actions gather real-world data; Observations allow course correction.*

### 🛠️ 工具调用 / Tool Use

现代 LLM（GPT-4, Claude, Gemini）支持 **function calling**：模型决定何时调用哪个工具。

```python
# Define tools the agent can use
tools = [
    {
        "name": "web_search",
        "description": "Search the web for current information",
        "parameters": {
            "type": "object",
            "properties": {
                "query": {"type": "string", "description": "Search query"}
            }
        }
    },
    {
        "name": "run_python",
        "description": "Execute Python code and return output",
        "parameters": {
            "type": "object",
            "properties": {
                "code": {"type": "string", "description": "Python code to run"}
            }
        }
    }
]

# pip install openai
import openai

client = openai.OpenAI()

response = client.chat.completions.create(
    model="gpt-4o",
    messages=[{"role": "user", "content": "What's 1234 * 5678?"}],
    tools=tools,
    tool_choice="auto"  # Model decides whether to use a tool
)

# Model returns: use run_python with code="print(1234 * 5678)"
# You execute the tool, send result back, model gives final answer
print(response.choices[0].message.tool_calls)
```

**关键点：** 模型**建议**调用工具，**你的代码**实际执行它——安全边界在这里！
*Key: the model **suggests** tool calls, **your code** actually executes them — the safety boundary is here!*

### 📐 规划模式 / Planning Patterns

| 模式 | 描述 | 适用场景 |
|------|------|---------|
| **ReAct** | 交替思考+行动 | 信息检索、研究任务 |
| **Plan-and-Execute** | 先整体规划，再逐步执行 | 复杂多步骤任务 |
| **Reflexion** | 执行后反思，自我纠错 | 代码生成、写作 |
| **Multi-Agent** | 多个 Agent 协作分工 | 大规模复杂任务 |

### ⚠️ Agent 的挑战 / Challenges

**😱 失控问题：** Agent 可能无限循环或采取意外行动 → 需要 **max_iterations** 限制
**💸 成本问题：** 每次 Thought-Action-Observation 都消耗 tokens，多步任务很贵
**🔒 安全问题：** Prompt injection 攻击（恶意网页内容欺骗 agent）是真实威胁
**🐌 速度问题：** 串行规划很慢；多 Agent 并行是方向

### 🧒 ELI5

AI Agent 就像一个会自己查资料的助手。你说"帮我订机票"，它不是直接回答，而是：想一下需要什么信息 → 去查机票网站 → 看结果 → 再想 → 再查 → 最后告诉你最好的选择。和普通 AI 的区别是它会"自己动手"！
*An AI Agent is like an assistant who can look things up themselves. You say "book me a flight" — instead of just answering, it thinks → searches → reads results → thinks again → searches more → tells you the best option. Unlike regular AI: it takes action!*
