## 💡 AGI 到底是什么？/ What Even Is AGI?

AGI（通用人工智能）没有统一定义，不同人的理解天差地别：

| 定义 / Definition | 谁这么说 / Proponent |
|---|---|
| 能做任何人类可以做的认知任务 | OpenAI 官方定义 |
| 能自主完成大多数经济任务 | OpenAI 内部操作定义 |
| 能自我改进的系统 | DeepMind 等 |
| 图灵测试通过 | 经典定义（已过时）|

> AGI doesn't have a universally accepted definition. OpenAI's operational definition is "a system that can autonomously complete most economically valuable tasks." Others require self-improvement loops.

## 🏛️ 两大阵营 / Two Camps

### 阵营 1：Scaling Wins（缩放定律派）
**核心论点:** 更大的模型 + 更多数据 + 更多算力 → 涌现能力持续出现
**代表:** Sam Altman, Demis Hassabis
**证据:** GPT-2 → GPT-3 → GPT-4 的质变跨越

Bigger models keep surprising us with emergent capabilities. Just keep scaling.

### 阵营 2：Architecture Change Needed（架构变革派）
**核心论点:** Transformer 有根本缺陷（无记忆、推理弱），需要新架构
**代表:** Yann LeCun (世界模型论), Gary Marcus
**证据:** LLM 仍然会算错 9.11 > 9.9，hallucinate 事实

Transformers lack persistent memory and true reasoning. We need something fundamentally different.

## 🔭 新兴架构 / Emerging Architectures

### 1. Mamba / State Space Models (SSM)
- 线性时间序列处理，**不需要 Attention**
- 长序列效率远超 Transformer (O(n) vs O(n²))
- 2024 年崛起，2025 年混合模型（Attention + SSM）开始流行

Linear-time sequence modeling without attention. Efficient for very long contexts.

### 2. Mixture of Experts (MoE) 演化
- GPT-4 据报道是 8 个专家的 MoE
- 每次 token 只激活部分专家 → 大模型，小推理成本
- 趋势：更细粒度的 MoE，每层 1000+ 专家

Only activate a subset of experts per token — big model capacity, small inference cost.

### 3. Retrieval-Augmented Everything
- 不只是 RAG for QA，而是**主动记忆检索**
- 模型训练时学会「何时去查、查什么」
- GraphRAG（微软）：用知识图谱结构化检索，而非纯向量相似度

Not just retrieval at query time — models learning when and what to retrieve during reasoning.

### 4. Test-Time Compute (推理时计算)
- OpenAI o3, DeepSeek R1 的核心：**推理时多想几步**
- 不是训练更大模型，而是推理时生成更多「思考链」
- 趋势：动态分配推理算力（简单问题快速回答，复杂问题深思熟虑）

Spending more compute at inference time beats just training bigger models for reasoning tasks.

## 🧮 可运行代码 / Runnable Python Snippet

探索现有 SSM 实现（Mamba 风格）：

```python
# pip install mamba-ssm  (requires CUDA)
# 或者用纯 Python 模拟 SSM 的核心思想

import numpy as np

def ssm_step(A, B, C, x, h):
    """
    Simplified State Space Model step.
    h: hidden state (memory)
    x: input token
    Returns: output y, new hidden state
    """
    h_new = A @ h + B * x    # update state
    y = C @ h_new             # project to output
    return y, h_new

# 模拟 3 个 tokens 的处理
A = np.array([[0.9, 0.1], [0.0, 0.8]])  # state transition
B = np.array([[1.0], [0.5]])             # input projection
C = np.array([[1.0, 0.0]])               # output projection

h = np.zeros((2, 1))  # initial hidden state
tokens = [1.0, 2.0, 3.0]

for i, x in enumerate(tokens):
    y, h = ssm_step(A, B, C, x, h)
    print(f"Token {i}: input={x:.1f}, output={y[0,0]:.3f}, state={h.flatten()}")
```

## 🧒 ELI5

AGI 就是「什么都会的 AI」。现在的 AI 很擅长特定任务（下棋、写文章、画画），但遇到从没见过的新任务就会卡壳。科学家们在争论：是「继续加大模型」就能解决，还是需要从头发明新方法？

AGI is "AI that can do anything." Current AI excels at specific tasks but struggles with genuinely novel ones. Scientists debate whether we just need bigger models, or a fundamentally new approach.
