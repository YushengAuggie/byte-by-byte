## 真实场景 / Real Scenario

你在做一个表单状态管理器，需要：
1. **深拷贝**初始状态（避免突变）
2. **展平**嵌套配置对象
3. **柯里化**验证函数（复用参数）

You're building a form state manager — deep clone to avoid mutation, flatten nested configs, curry validators for reuse.

## 1. Deep Clone — 深拷贝

**❌ 错误做法：浅拷贝**
```typescript
const copy = { ...original };  // nested objects still share reference!
const copy2 = Object.assign({}, original);  // same problem
```

**✅ 生产级实现：**
```typescript
function deepClone<T>(obj: T): T {
  // Modern: use structuredClone (available in Node 17+, all modern browsers)
  return structuredClone(obj);
}

// Manual fallback (interview version)
function deepCloneManual<T>(obj: T): T {
  if (obj === null || typeof obj !== 'object') return obj;
  if (obj instanceof Date) return new Date(obj.getTime()) as T;
  if (Array.isArray(obj)) return obj.map(deepCloneManual) as T;
  
  const clone = {} as T;
  for (const key in obj) {
    if (Object.prototype.hasOwnProperty.call(obj, key)) {
      clone[key] = deepCloneManual(obj[key]);
    }
  }
  return clone;
}
```

**What `structuredClone` handles:** Arrays, Dates, Maps, Sets, RegExp, nested objects ✅
**What it doesn't handle:** Functions, DOM nodes, class instances with methods ❌

## 2. Flatten — 展平嵌套对象

**场景:** API 返回嵌套配置，你需要展平成点分路径

```typescript
const input = {
  user: {
    name: "Alice",
    address: { city: "SF", zip: "94102" }
  }
};

// Expected output:
// { "user.name": "Alice", "user.address.city": "SF", "user.address.zip": "94102" }

function flattenObject(
  obj: Record<string, unknown>,
  prefix = ""
): Record<string, unknown> {
  return Object.entries(obj).reduce((acc, [key, val]) => {
    const fullKey = prefix ? `${prefix}.${key}` : key;
    
    if (val !== null && typeof val === 'object' && !Array.isArray(val)) {
      // Recurse into nested objects
      Object.assign(acc, flattenObject(val as Record<string, unknown>, fullKey));
    } else {
      acc[fullKey] = val;
    }
    return acc;
  }, {} as Record<string, unknown>);
}
```

## 3. Curry — 柯里化

**场景:** 验证函数，参数复用

```typescript
// Without curry: repeat min/max every time
const validate = (min: number, max: number, value: number) => 
  value >= min && value <= max;

// With curry: create reusable validators
function curry<T extends unknown[], R>(
  fn: (...args: T) => R
): (...args: Partial<T>) => unknown {
  return function curried(...args: unknown[]) {
    if (args.length >= fn.length) {
      return fn(...args as T);
    }
    return (...moreArgs: unknown[]) => curried(...args, ...moreArgs);
  };
}

const curriedValidate = curry(validate);
const isValidAge = curriedValidate(0)(120);    // min=0, max=120
const isValidScore = curriedValidate(0)(100);  // min=0, max=100

console.log(isValidAge(25));    // true
console.log(isValidScore(150)); // false
```

## 猜猜输出 / Quiz

```javascript
const obj = { a: 1 };
const clone = { ...obj };
clone.a = 99;
console.log(obj.a);  // ???

const nested = { a: { b: 1 } };
const shallowCopy = { ...nested };
shallowCopy.a.b = 99;
console.log(nested.a.b);  // ???
```

<details><summary>显示答案 / Show Answer</summary>

`obj.a = 1` — primitive values ARE copied by value ✅
`nested.a.b = 99` — nested objects are still shared references ❌

This is WHY deep clone matters for nested state!
</details>

## When to Use / When NOT to Use

| 情况 | 选择 |
|------|------|
| 深拷贝简单对象 | `structuredClone(obj)` |
| 深拷贝含函数的类实例 | 自己实现 or 用 lodash `_.cloneDeep` |
| 展平 API 响应 | `flattenObject()` |
| 展平 + 还原 | 用 `flat-unflatten` npm package |
| 柯里化工具函数 | `curry()` or Ramda/lodash `_.curry` |
| 柯里化 React 事件处理 | 直接用箭头函数，别过度抽象 |

## 🧒 ELI5

**深拷贝**就像用复印机复印一份文件，改副本不影响原件。浅拷贝只复印了封面，里面的内容还是共享的。

**展平**就像把一个嵌套的文件夹结构变成一个清单，用点号表示层级：`用户/地址/城市` → `user.address.city`。

**柯里化**就像预填表单。你先填好"最小值=0"，保存这个半成品，以后每次只需要填"最大值"就行了。

Deep clone = full photocopy, not just the cover. Flatten = turn nested folders into a dot-path list. Curry = pre-fill a form's first field and save it for later reuse.
