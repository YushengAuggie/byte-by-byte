## 真实场景 / Real Scenario

你在构建一个 dashboard，需要从前端提交一个表单来更新用户资料。你有两个选择：写一个 API Route (`/api/update-profile`)，或者用 Next.js 13+ 的 **Server Actions**。哪个更好？什么时候用哪个？

*You're building a dashboard with a profile update form. You have two options: write an API Route (`/api/update-profile`) or use Next.js 13+ **Server Actions**. Which is better? When do you use each?*

---

## 概念对比 / Core Concepts

### API Routes (pages/app router)
```typescript
// app/api/update-profile/route.ts
import { NextRequest, NextResponse } from 'next/server'

export async function POST(req: NextRequest) {
  const body = await req.json()
  const { userId, name, bio } = body
  
  // validate, update DB
  await db.user.update({ where: { id: userId }, data: { name, bio } })
  
  return NextResponse.json({ success: true })
}
```

### Server Actions (Next.js 14+)
```typescript
// app/profile/actions.ts
'use server'

import { revalidatePath } from 'next/cache'

export async function updateProfile(formData: FormData) {
  const name = formData.get('name') as string
  const bio = formData.get('bio') as string
  
  // runs on SERVER — direct DB access, no HTTP overhead
  await db.user.update({ where: { id: getCurrentUserId() }, data: { name, bio } })
  
  revalidatePath('/profile')  // auto-revalidate cache
}

// Usage in component:
// <form action={updateProfile}>
//   <input name="name" />
//   <button type="submit">Save</button>
// </form>
```

## 猜猜这段代码的行为 / What does this do?

```typescript
// app/profile/page.tsx
'use client'

import { updateProfile } from './actions'

export default function ProfileForm() {
  return (
    <form action={updateProfile}>
      <input name="name" defaultValue="Alice" />
      <button type="submit">Save</button>
    </form>
  )
}
```

A) 报错：Server Action 不能在 Client Component 中使用
B) 正常工作：点击 Save 时调用服务器函数
C) 报错：需要 `preventDefault()`
D) 报错：`action` 不接受函数

**Answer: B** — Server Actions 可以从 Client Components 调用，Next.js 自动生成安全的 RPC 调用。

## ❌ Bad vs ✅ Good

```typescript
// ❌ 旧方式：Client → fetch → API Route → DB
async function handleSubmit(e: React.FormEvent) {
  e.preventDefault()
  await fetch('/api/update-profile', {
    method: 'POST',
    body: JSON.stringify({ name }),
  })
  router.refresh()  // manual cache invalidation
}

// ✅ 新方式：Server Action (直接调用)
// 'use server' 函数可以直接被 form action 使用
// 不需要 fetch、不需要 API Route、自动 revalidate
<form action={updateProfile}>
  <input name="name" />
  <button>Save</button>
</form>
```

## When to Use / When NOT to Use

| | API Routes | Server Actions |
|---|---|---|
| ✅ Use when | Public API / third-party consumers | Form submissions, mutations from UI |
| ✅ Use when | Complex request/response logic | Direct DB access without HTTP |
| ✅ Use when | Webhooks, streaming, custom headers | Need auto cache revalidation |
| ❌ Avoid when | Simple UI mutations | Public API used by mobile/external |
| ❌ Avoid when | — | Need fine-grained HTTP control |

**规则:** Server Actions 适合内部表单/变更；API Routes 适合对外暴露的接口。

## 🧒 ELI5
以前点按钮要：前端→发请求→后端→改数据库→回来。Server Actions 就像在前端直接按一个"魔法按钮"，直接改数据库，中间那些步骤 Next.js 帮你搞定了。

*Before: frontend → HTTP request → backend API → database. Server Actions: frontend → magic button → database directly. Next.js handles the "how" for you.*
