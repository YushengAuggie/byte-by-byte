## 可运行代码：三种方案实现同一任务 / Runnable: All Three Approaches

```python
# pip install openai chromadb sentence-transformers

# Task: Answer questions about a company's internal docs
SAMPLE_DOCS = [
    "Our refund policy: customers can return items within 30 days.",
    "Premium users get 24/7 support. Basic users get email-only support.",
    "API rate limits: 1000 req/min for paid tier, 100 req/min for free tier.",
]
QUESTION = "What support do basic users get?"

# ─── Approach 1: Prompting Only ───────────────────────────────
def approach_prompting(question: str) -> str:
    """Stuff all context into the prompt. Simple but costly for large docs."""
    context = "\n".join(SAMPLE_DOCS)
    prompt = f"Context:\n{context}\n\nQuestion: {question}\nAnswer:"
    # In real code: call openai.chat.completions.create(...)
    return f"[Prompt] Context: {len(context)} chars → answer question"

# ─── Approach 2: RAG ──────────────────────────────────────────
from sentence_transformers import SentenceTransformer
import numpy as np

def build_rag_index(docs: list[str]):
    """Build a simple vector index (use Chroma/Pinecone in prod)."""
    model = SentenceTransformer('all-MiniLM-L6-v2')
    embeddings = model.encode(docs)  # shape: (N, 384)
    return model, embeddings

def approach_rag(question: str, docs: list[str]) -> str:
    """Retrieve top-k relevant docs, then generate."""
    model, embeddings = build_rag_index(docs)
    q_emb = model.encode([question])                       # query embedding
    
    # Cosine similarity
    scores = np.dot(embeddings, q_emb.T).flatten()
    top_k_idx = np.argsort(scores)[::-1][:2]              # top 2 docs
    retrieved = [docs[i] for i in top_k_idx]
    
    context = "\n".join(retrieved)
    # Then call LLM with ONLY the retrieved context
    return f"[RAG] Retrieved {len(retrieved)} docs → answer (hallucination risk ↓)"

# ─── Approach 3: Fine-tuning (conceptual) ─────────────────────
def approach_finetune_training_data(docs: list[str]) -> list[dict]:
    """
    For fine-tuning: generate Q&A pairs from docs.
    Real fine-tune: upload to OpenAI/Hugging Face, train LoRA adapters.
    """
    pairs = []
    for doc in docs:
        pairs.append({
            "messages": [
                {"role": "user", "content": "What is our policy on refunds?"},
                {"role": "assistant", "content": doc}
            ]
        })
    return pairs  # Upload to openai.files, then openai.fine_tuning.jobs.create

# Run comparison
print(approach_prompting(QUESTION))
print(approach_rag(QUESTION, SAMPLE_DOCS))
print(f"[Fine-tune] Training data: {len(approach_finetune_training_data(SAMPLE_DOCS))} pairs")
```

## 生产决策指南 / Production Decision Guide

**选 Prompting 当 / Use Prompting when:**
- 文档 < 10 pages (能塞进 context window)
- 任务通用，不需要特定风格
- 快速原型验证

**选 RAG 当 / Use RAG when:**
- 知识库 > 100 pages 或需要实时更新
- 需要可追溯来源 (用户需要知道答案来自哪里)
- 企业内部文档/FAQ/代码库搜索
- 幻觉是高风险 (法律/医疗)

**选 Fine-tuning 当 / Use Fine-tuning when:**
- 需要特定的输出格式/风格 (prompt 无法可靠控制)
- 推理成本敏感 (微调后用小模型替换大模型)
- 领域词汇特殊 (代码风格、医学术语)
- 有 >1000 个高质量训练样本

**混合最佳 / Best combo:**
```
RAG + Fine-tuning = 知识时效性 + 行为定制
(企业级LLM应用的标准架构)
```

## 🧒 ELI5

三种学习方式：
- **Prompting**: 考试时把课本放桌上，随时翻 (不用预先学，但翻书慢)
- **RAG**: 考试前用搜索引擎找最相关的几页，只带那几页进考场
- **Fine-tuning**: 提前把知识背进脑子，考试时不带任何资料 (速度最快，但需要提前准备)
