Overview / 概述

中文：

戳气球是区间动态规划（Interval DP）的经典代表，也是 LeetCode Hard 中口碑最好的"顿悟题"之一。它难在代码之前——在于一个反直觉的逆向转化：不是想第一个戳哪个，而是想最后一个戳哪个。一旦接受这个视角，整道题瞬间变得清晰。区间 DP 是高级 DP 的核心模式，掌握它你就能解 Matrix Chain Multiplication、Strange Printer、Zuma Game 等一系列难题。

English:

Burst Balloons is the canonical Interval DP problem and one of LeetCode Hard's most celebrated "aha" moments. It's hard not because the code is long, but because of a counterintuitive reversal: instead of asking "which balloon do I burst first?", ask "which balloon do I burst last?" Once that flip clicks, the whole problem unfolds cleanly. Interval DP is a critical advanced pattern that unlocks a whole family of seemingly intractable problems.

Part 1: Theory / 理论基础 (5 min)

为什么暴力解不行 / Why Brute Force Fails

中文：

最直觉的做法是枚举所有戳气球的顺序。n 个气球 → n! 种顺序。即使 n=10 就是 3,628,800 种；n=500 完全不可行。

递归 + 记忆化的第一直觉是：定义 dp[i][j] = 在区间 [i, j] 内能获得的最大金币。但这里有个致命缺陷：戳掉气球 k 之后，k 的左右邻居会成为新邻居，这意味着左子问题 [i, k-1] 和右子问题 [k+1, j] 共享了一个动态变化的边界——子问题之间相互依赖，无法独立求解，记忆化无法工作。

English:

The intuitive approach enumerates all burst orderings: n balloons → n! orderings. Even n=10 gives 3.6M; n=500 is completely infeasible.

The first memoization instinct: define dp[i][j] = max coins in range [i, j]. But there's a fatal flaw: bursting balloon k makes its left and right neighbors adjacent. This means left subproblem [i, k-1] and right subproblem [k+1, j] share a dynamically changing boundary — subproblems depend on each other. Memoization breaks.

区间 DP 的核心逆转 / The Key Reversal

中文：

解题的钥匙是这个思维翻转：

不问"先戳哪个"，而问"最后戳哪个"。

定义 dp[i][j] = 在开区间 (i, j) 内戳破所有气球能获得的最大金币（i 和 j 本身是边界哨兵，不被戳破）。

假设气球 k 是区间 (i, j) 中最后一个被戳破的：

  • 戳破 k 之前，区间 (i, k) 和 (k, j) 里的气球都已经消失
  • 此刻 k 的左邻居是 i，右邻居是 j（它们是边界，始终存在）
  • 戳破 k 的收益 = nums[i] × nums[k] × nums[j]
  • 总收益 = dp[i][k] + nums[i] × nums[k] × nums[j] + dp[k][j]

子问题现在是真正独立的！求解 dp[i][k] 时，边界是 i 和 k，不受 k 右边的影响。

English:

The key is this mental flip:

Don't ask "which to burst first" — ask "which to burst last."

Define dp[i][j] = max coins from bursting all balloons in the OPEN interval (i, j), where i and j are sentinel boundaries that never get burst.

If balloon k is the last one burst in interval (i, j):

  • Before bursting k, all balloons in (i, k) and (k, j) are already gone
  • At the moment of bursting k, its only neighbors are the fixed sentinels i and j
  • Coins from bursting k = nums[i] × nums[k] × nums[j]
  • Total = dp[i][k] + nums[i] × nums[k] × nums[j] + dp[k][j]

Subproblems are now truly independent — solving dp[i][k] uses fixed boundaries i and k, unaffected by anything to the right.

状态转移方程 / Recurrence

dp[i][j] = max over all k in (i, j) of:
    dp[i][k] + nums[i] × nums[k] × nums[j] + dp[k][j]

Base case: dp[i][j] = 0 when j - i < 2  (no balloons in the interval)
Answer: dp[0][n+1]  (full padded array, open interval)

遍历顺序 (Traversal Order): 短区间先算，长区间后算（bottom-up by interval length）。

Part 2: Step-by-Step Implementation / 一步一步实现 (8 min)

完整代码 / Full Implementation

from typing import List

def maxCoins(nums: List[int]) -> int:
    # Step 1: Add sentinel boundaries (value 1 on both sides)
    # This avoids checking array bounds when the "last balloon" has no neighbors
    nums = [1] + nums + [1]
    n = len(nums)  # Now n = original_len + 2

    # Step 2: Initialize DP table
    # dp[i][j] = max coins from bursting all balloons in OPEN interval (i, j)
    # i and j themselves are never burst — they're the "surviving" boundaries
    dp = [[0] * n for _ in range(n)]

    # Step 3: Fill by increasing interval length
    # length = j - i; minimum interval with one balloon inside has length = 2
    for length in range(2, n):
        for left in range(0, n - length):
            right = left + length

            # Step 4: Try each k as the LAST balloon burst in (left, right)
            for k in range(left + 1, right):
                # At the moment k is burst:
                #   - (left, k) is already empty  → contributes dp[left][k]
                #   - (k, right) is already empty → contributes dp[k][right]
                #   - k sees left and right as neighbors → nums[left] * nums[k] * nums[right]
                coins = (dp[left][k]
                         + nums[left] * nums[k] * nums[right]
                         + dp[k][right])
                dp[left][right] = max(dp[left][right], coins)

    # Step 5: Answer is entire array (open interval from sentinel 0 to sentinel n-1)
    return dp[0][n - 1]

可选：重建最优戳气球顺序 / Reconstructing the Optimal Order

def maxCoins_with_path(nums: List[int]) -> tuple:
    nums = [1] + nums + [1]
    n = len(nums)
    dp = [[0] * n for _ in range(n)]
    # choice[i][j] = which k was last burst in interval (i, j)
    choice = [[0] * n for _ in range(n)]

    for length in range(2, n):
        for left in range(0, n - length):
            right = left + length
            for k in range(left + 1, right):
                coins = dp[left][k] + nums[left] * nums[k] * nums[right] + dp[k][right]
                if coins > dp[left][right]:
                    dp[left][right] = coins
                    choice[left][right] = k  # record the optimal last balloon

    def reconstruct(left, right):
        """Returns list of balloon indices burst in optimal order (last to first recursively)."""
        if left + 1 >= right:
            return []
        k = choice[left][right]
        # Recursively: burst left sub-interval first, then right, then k
        return reconstruct(left, k) + reconstruct(k, right) + [k]

    order = reconstruct(0, n - 1)
    return dp[0][n - 1], [i - 1 for i in order]  # adjust for 0-indexed original array

SpaceO(n²)DP table; O(n²) intervals to store

Part 3: Edge Cases & Gotchas / 边界情况 (2 min)

陷阱一：开区间 vs 闭区间 / Open vs Closed Interval

中文： dp[i][j] 表示的是开区间 (i, j)，i 和 j 本身不在这个区间里，不会被戳破。许多人误以为包含端点，导致重复计算或错误索引。

English: dp[i][j] covers the OPEN interval (i, j). Balloons at index i and j are boundaries — never burst in this subproblem. Confusing this causes double-counting.

# WRONG (common mistake): iterating k including boundaries
for k in range(left, right + 1):   # includes left and right — wrong!

# CORRECT: k is strictly between left and right
for k in range(left + 1, right):   # open interval, excludes boundaries

陷阱二：遍历顺序 / Traversal Order

# WRONG: iterating by (i, j) pairs in any order
# dp[i][k] and dp[k][j] may not be filled when you need them

# CORRECT: always iterate by length (small intervals before large)
for length in range(2, n):         # length-2 before length-3 before...
    for left in range(0, n - length):
        right = left + length

陷阱三：哨兵值必须是 1 / Sentinels Must Be 1

中文： 哨兵为 1，是因为戳最后一个气球时，哨兵会作为它的邻居参与计算：1 × nums[k] × 1。若哨兵设为 0，所有收益都会变成 0。

English: Sentinels are 1 because when you burst the very last balloon in the entire array, it sees sentinels as both neighbors: 1 × nums[k] × 1. Setting sentinels to 0 makes all coins 0.

陷阱四：单气球输入 / Single Balloon Edge Case

# nums = [5] → padded = [1, 5, 1]
# dp[0][2]: k=1 → 0 + 1×5×1 + 0 = 5
# Returns 5 ✓

工程中的实际场景 / Production Engineering

数据库查询优化 (Database Query Planning)

Join ordering is a classic interval DP problem: given tables T₁, T₂, ..., Tₙ, find the optimal order of joins. PostgreSQL's planner solves small join counts exactly with DP, falling back to greedy for large n.

Optimal parenthesization for expression trees — same matrix-chain structure — appears in register allocation and instruction scheduling.

Part 5: Interview Simulation / 面试模拟 (3 min)

Q1: Walk me through your approach to this problem.

"I'd start with brute force — try all orderings, O(n!), clearly too slow. Then try memoization: dp[i][j] = max coins in range [i, j]. But the problem is when you burst balloon k, its neighbors change, so subproblems aren't independent — memoization doesn't work cleanly. The key insight is reversing: instead of asking which to burst first, ask which to burst last in an interval. If k is the last balloon burst in open interval (i, j), then i and j are fixed boundaries at that moment, giving coins = nums[i] × nums[k] × nums[j] + dp[i][k] + dp[k][j]. Now subproblems are independent. O(n³) time, O(n²) space."

Q2: Why does "last burst" give independent subproblems but "first burst" doesn't?

"With 'first burst': bursting k immediately merges its left and right contexts — the left sub-interval now has a new right neighbor (the right of k), coupling the two halves. With 'last burst': we declare k off-limits until everything else in (i, j) is gone. The boundary of each sub-interval [i, k] and [k, j] is fixed and never changes — true independence."

Q3: Can we do better than O(n³)?

"There are O(n²) distinct intervals and each must be computed, so O(n²) is a lower bound on space. For time, there's no known better algorithm for this exact problem. In practice, with n ≤ 500 (LeetCode's constraint), O(n³) = 125M operations — fast enough. If n were larger, you'd need approximations or problem-specific heuristics."

Q4: How do you handle the edge case where the array has a single element?

"With sentinels: padded = [1, x, 1]. dp[0][2] with k=1 gives 1 × x × 1 = x. Returns x correctly. No special handling needed — the sentinel approach naturally handles all edge cases."

Q5: Name two problems that use the same Interval DP pattern.

"1. Strange Printer (LC #664): minimize turns to print a string. dp[i][j] = min turns for s[i..j]; fix the last character group printed in the interval. 2. Minimum Cost to Merge Stones (LC #1000): repeatedly merge adjacent stones; dp[i][j] = min cost to reduce stones[i..j] to as few piles as possible. Both use the same 'fix the last operation, recurse both sides' structure."

总结 / Summary

中文：

关键点内容
核心逆转"最后戳哪个" 而非 "先戳哪个"
为什么有效最后一个被戳破时，边界是固定的 → 子问题独立
遍历顺序按区间长度从小到大
边界处理添加值为 1 的哨兵节点
时间复杂度O(n³)
空间复杂度O(n²)
适用模式任何"在区间内选最后操作"的问题

English:

The mental model for Interval DP is deceptively simple once internalized: fix the last action, not the first. This transforms a problem with exponential state dependency into one with clean, nested independent subproblems. Burst Balloons is the hardest and most instructive example of this pattern — if you can solve it from scratch, you've unlocked the full family.
